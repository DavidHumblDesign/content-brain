## Phase 4 — Daily content engine (weeks 1–4 build the muscle)

- [ ] Cadence: 5 posts/week minimum, daily once a backlog exists
- [ ] Rotation: Mon Pillar 1 / Tue Pillar 3 / Wed Pillar 2 / Thu Pillar 1 / Fri Pillar 3 (adjust based on DMs generated)
- [ ] Every post ends with: "DM 'AUDIT' + your URL." Same words. Don't get cute.
- [ ] Caption voice: founder-speed, no fluff, "you" language, bad-vs-good contrasts, real example. Run through anti-ai-writing skill before posting.
- [ ] First week: each post explicitly plants the master positioning so the top 5 on the profile are consistent
- [ ] 30-day review: rank posts by AUDIT DMs generated (not likes). Top 3 → repurpose, change one variable (hook, design, or angle).
- [ ] Skip Ruben's "strip the CR tag" trick — design your own.

## Phase 5 — Engagement (daily, ~30 min)

- [ ] Build a target list of ~50 Ryan-shaped accounts: early-seed AI/SaaS founders in Austin/SF/NYC/Boston, posting about landing pages, conversion, growth, UX, onboarding
- [ ] 5 substantive comments/day on those accounts. 15+ words minimum, audit-style observation, not validation.
- [ ] Connect with Ryan-shaped founders proactively. No pitch on connection. Connect → engage → DMs come.
- [ ] Skip: Slack pod groups, comment-trade rings, "support each other" reciprocity (brand-incompatible + LinkedIn penalizes)

## Phase 7 — Metrics

- [ ] North star: AUDIT DMs received / week → audits delivered → retainers booked

- [ ] Math: at $5,999/mo retainer, one new client per quarter from LinkedIn = ~$72K/year. The whole effort pays back 20x. Quality > volume.
